# Final-project submission checklist

- [x] Streamlit application with an HR-facing dashboard and working navigation.
- [x] PDF resume upload (single or multiple files), extraction, cleaning, and readable preview.
- [x] Job description entry and optional JD PDF extraction.
- [x] Gemini + LangChain structured-analysis path when `GEMINI_API_KEY` is configured.
- [x] Reliable local skill-based fallback when Gemini is unavailable.
- [x] Candidate summary, skills comparison, score, recommendation, justification, and interview questions.
- [x] Candidate ranking, side-by-side comparison, and CSV export.
- [x] Email-based resume de-duplication and multiple demo CVs.
- [x] Two sample job descriptions in `assets/samples/`.
- [x] README, requirements, automated tests, and this checklist.
- [ ] Record the YouTube demonstration using `docs/demo-video-script.md` and add its link to README.
- [ ] Capture screenshots of the dashboard, resume report, candidate ranking, and pipeline for the GitHub repository.
- [ ] Deploy from GitHub to Streamlit Community Cloud and add the public URL to README.
