# TalentOS demonstration dataset

This folder contains synthetic, non-identifying data created solely for testing and demonstrating the project. It is not a real recruitment dataset and must not be used to make real hiring decisions.

Files:

- `candidate_resume_dataset.csv` — summary fields derived from the bundled synthetic demo CVs.
- `job_description_dataset.csv` — synthetic job descriptions used for matching demonstrations.

The original readable CV and job-description samples remain in `assets/samples/` for PDF/text extraction demonstrations.
