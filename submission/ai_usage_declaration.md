# AI Usage Declaration

This project was developed as part of an academic submission. The declaration below is provided to comply with the requirement for transparent disclosure of AI assistance.

## AI Tools Used
- **OpenAI Codex / ChatGPT:** Used as a development assistant for code review, debugging, documentation drafting, test guidance, and UI/workflow improvement suggestions.
- **Google Gemini API through LangChain:** Integrated into the application as an optional runtime service for structured resume analysis and conversational assistance when the project owner configures a valid API key.

## How AI Was Used
- Codex/ChatGPT assistance was used to review and improve implementation approaches, troubleshoot errors, draft documentation, and propose automated tests. All generated suggestions were reviewed and integrated by the student.
- The application integrates Gemini through LangChain for structured candidate analysis when configured.
- The system includes deterministic local scoring and workspace retrieval fallbacks so it remains usable without an API key.

## Sections Written or Assisted by AI
- README content and deployment instructions
- Submission-package documentation, report wording, and the video outline
- Some code-review, testing, debugging, and UI improvement suggestions

## Parts Implemented by the Student
- Final project decisions, review, integration, and testing
- Streamlit pages, workflow configuration, and project setup
- Resume/job upload configuration, database integration, candidate ranking, and ATS workflow implementation
- Validation of generated changes and preparation of the final submission package
